# Symfony Dojo

## Description

Programme à piloter dans `claude code` pour apprendre à coder un backend en Symfony (API JSON pure), en partant d'un socle PHP déjà connu — bases du framework (routing, injection de dépendances, Doctrine) puis construction progressive d'une API REST complète (persistance, validation, authentification, tests).

## Utilisation

1. Ce dossier contient déjà `CLAUDE.md` et `PROGRAMME.md`.
2. Dans un terminal, se placer dans ce dossier et lancer :
    ```
    claude
    ```
3. Dans `claude code`, écrire le premier prompt :
    ```
    On commence le jour 1.
    ```

## Mini-projet fil rouge

Une API JSON de bibliothèque personnelle (voir `PROGRAMME.md` pour le détail des phases et des défis quotidiens).

## Notes

Le contenu du code produit pendant le programme est fictif, seuls les fichiers `CLAUDE.md` et `PROGRAMME.md` définissent le déroulé du dojo.
